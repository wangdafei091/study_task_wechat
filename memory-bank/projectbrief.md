# 项目概述

## 项目名称
学习任务微信小程序 (Study Task WeChat Mini Program)

## 核心目标
帮助小朋友养成良好学习习惯的任务管理工具，通过任务管理、积分奖励等机制，培养自律学习的能力。

## 项目范围
- **任务管理系统**：支持学习、习惯、兴趣三种任务类型，包含重复任务和必做任务功能
- **星星积分系统**：完成任务获得星星，支持有效期管理和FIFO消费策略
- **奖励兑换机制**：用星星兑换各种奖励，激励学习
- **多用户角色**：支持家长和小朋友角色切换
- **消息通知系统**：及时提醒任务状态和系统消息
- **数据分析功能**：提供任务完成情况和趋势分析

## 技术约束
- **平台**：微信小程序原生框架
- **架构**：领域驱动设计(DDD)架构
- **存储**：微信小程序本地存储
- **测试**：Jest单元测试框架，目标覆盖率85%+

## 成功标准
1. 功能完整性：核心功能模块稳定运行
2. 代码质量：遵循DDD架构原则，测试覆盖率≥85%
3. 用户体验：界面友好，操作流畅
4. 性能指标：页面加载快速，数据操作高效
5. 维护性：代码结构清晰，文档完善
