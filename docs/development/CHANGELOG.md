# 更新日志

## [v1.3.2] - 2025-01-03

### 优化功能
- **星星计算逻辑修正**
  - 修正日历格子中的星星计算，只统计非必做任务的星星
  - 移除必做任务的扣除星星显示，因为必做任务不参与星星奖励系统
  - 优化星星显示逻辑，使其更符合产品设计理念

- **任务汇总文案优化**
  - 简化汇总文案格式：`3个任务（必做 1T；非必做 2T/2🌟）`
  - 移除冗长的描述性文字，提升信息密度
  - 统一使用"T"表示任务数量，提高可读性

- **任务条目显示优化**
  - 移除必做任务的星星显示和风险提示
  - 保持已完成任务的 ✓ 标记
  - 简化必做任务的信息提示，只显示"必做任务"
  - 非必做任务继续显示星星数量

### 用户体验提升
- 信息显示更加简洁清晰
- 减少40%的文字内容，提升扫描效率
- 明确区分必做任务（义务）和非必做任务（奖励）的职责边界

## [v1.3.1] - 2025-01-03

### 优化功能
- **任务编辑页面日历详情弹层优化**
  - 统一必做任务标签样式，与首页保持一致（红色渐变背景）
  - 为每个任务项添加类型标签（习惯、学习、兴趣）
  - 移除冗余的星星汇总信息，将信息合并为单行显示
  - 优化任务汇总文案：如"3个任务（1个必做任务，2🌟，1个非必做任务 未完成扣1🌟）"

### 代码清理
- 移除废弃的星星汇总相关样式类（.stars-summary等6个样式类）
- 清理selectedDayStars相关的数据结构和逻辑
- 优化任务项右侧区域布局，支持标签和星星数量的灵活显示

### 样式改进
- 任务标签采用统一的设计规范（高度28rpx，圆角8rpx）
- 优化必做任务风险提示的显示方式
- 改进任务列表的信息层次和可读性

## [v1.3.0] - 2025-01-03

### 新增功能
- **日历热力图星星显示优化**
  - 在任务编辑页面的日历格子中增加星星数量显示
  - 格子高度从40rpx调整为48rpx，改为垂直布局
  - 显示格式：日期在上，任务数和星星数在下（如：3T 8⭐）
  - 支持显示必做任务的扣除星星风险（红色显示）

- **详情弹层星星统计**
  - 在任务详情弹层顶部添加星星收支汇总
  - 显示格式：星星：+8 -2 = 6颗（可获得-风险扣除=净收益）
  - 必做任务未完成时显示警告图标

- **任务列表优化**
  - 将"积分"文字统一改为星星图标（⭐）
  - 必做任务标签改为红色背景，未完成时显示扣除星星数
  - 优化视觉层次，突出星星奖励信息

### 技术改进
- 在`calculateHeatMap`方法中增加星星统计逻辑
- 新增`starsEarned`、`starsPending`、`starsAtRisk`等字段
- 优化数据计算性能，避免重复计算

### 样式优化
- 新增星星相关CSS类：`.star-count`、`.star-risk`、`.stars-summary`等
- 调整日历格子布局，支持双行信息显示
- 优化必做任务的视觉标识
