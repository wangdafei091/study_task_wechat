## [v3.1.1] - 2026-02-28

### 新增功能
- **单元测试体系**
  - 建立完整的单元测试体系，覆盖核心业务逻辑
  - 使用Jest测试框架，支持独立运行和覆盖率报告
  - 创建test目录结构：models、services、utils、__mocks__
  - 创建测试配置jest.config.js和Jest环境设置jest-setup.js

### 测试覆盖
- **工具函数测试**
  - dateUtils: 43个测试用例，覆盖日期格式化、计算、比较等
  - formatUtils: 22个测试用例，覆盖数字格式化、日期时间格式化

- **领域模型测试**
  - Task模型: 52个测试用例，覆盖构造函数、验证、状态转换等

- **应用服务测试**
  - StarService: 28个测试用例，覆盖星星计算、消费、过期处理等

### 测试运行
- 所有145个测试用例全部通过
- 覆盖率报告生成在coverage/目录
- 测试命令：
  - `npm test` - 运行所有测试
  - `npm run test:watch` - 监听模式
  - `npm run test:coverage` - 生成覆盖率报告

### 技术改进
- 添加Mock存储适配器，模拟微信存储
- 添加全局logger Mock，避免测试时调用真实日志
- 配置Jest覆盖率阈值，确保测试质量

### 测试范围说明
- **包含的范围（单元测试）**
  - 领域模型：Task、Star、Reward等
  - 应用服务：StarService、TaskService等
  - 工具函数：dateUtils、formatUtils等

- **不包含的范围（页面和UI）**
  - 页面交互、表单提交、页面跳转
  - UI渲染、样式正确性、动画效果
  - 微信API调用、端到端流程
