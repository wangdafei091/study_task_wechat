## 文档分类说明

### 📖 核心文档
- **持续维护**：随项目发展持续更新
- **新人必读**：新开发者入门的重要参考
- **规范指导**：指导日常开发工作

### 📝 专项记录
- **历史参考**：记录特定问题的解决过程
- **经验积累**：提供类似问题的解决思路
- **过程追溯**：便于回顾项目演进历程

## 使用建议

1. **新开发者**：
   - 优先阅读核心开发文档
   - 根据负责模块查看相关专项记录

2. **问题排查**：
   - 先查看故障排除文档
   - 再搜索相关的专项修复记录

3. **功能开发**：
   - 遵循编码标准和工作流程
   - 参考相似功能的实现记录

4. **文档维护**：
   - 重大修改更新核心文档
   - 专项修复可创建独立记录文档
