# 学习任务微信小程序用户指南

## 简介

学习任务微信小程序是一个帮助小朋友养成良好学习习惯的任务管理工具。通过创建和完成任务，小朋友可以获得星星奖励，并使用这些星星兑换奖品，从而培养自律学习的能力。

## 主要功能

- 创建和管理学习、习惯和兴趣三种类型的任务
- 查看每日任务进度和完成情况
- 任务热力图展示学习压力情况
- 星星奖励系统激励小朋友完成任务
- 即将到期任务提醒
- 必做任务机制培养责任感
- 奖池系统提供兑换奖励功能

## 使用指南

### 1. 创建任务

1. 在首页点击右下角的"+"按钮
2. 选择任务类型：学习、习惯或兴趣
3. 填写任务标题、描述和时间
4. 设置优先级和星星奖励数量
5. 选择是否设为必做任务
6. 点击"保存"按钮创建任务

### 2. 完成任务

1. 在首页的任务列表中找到要完成的任务
2. 点击任务项右侧的圆圈标记任务完成
3. 系统会自动记录完成时间并发放星星奖励
4. 完成的任务会显示在已完成列表中

### 3. 使用星星奖励

1. 进入"奖池"页面
2. 查看可兑换的奖励项目
3. 选择想要兑换的奖励
4. 点击"兑换"按钮，使用星星兑换奖励
5. 兑换成功后，相应的星星会被扣除

### 4. 查看进度统计

1. 进入"统计"页面
2. 查看任务完成率和星星获取情况
3. 通过热力图了解每日任务分布
4. 查看连续完成天数和其他统计数据

## 特色功能

### 必做任务

必做任务是一种特殊的任务类型，具有以下特点：
- 如果在截止日期前未完成，会扣除相应的星星作为惩罚
- 系统会优先提醒必做任务
- 帮助小朋友培养责任感和时间管理能力

### 星星有效期

为了鼓励小朋友及时使用获得的星星，系统设置了星星有效期机制：
- 任务完成获得的星星有不同的有效期
- 星星消费时，系统会优先使用即将过期的星星
- 在"星星"页面可以查看星星的有效期情况
- 星星过期前，系统会发送提醒消息

### 任务模板

频繁创建相似任务时，可以使用任务模板功能：
1. 在任务编辑页面，选择"保存为模板"
2. 给模板命名并保存
3. 创建新任务时，可以选择已有模板快速填写

## 小技巧

1. **合理设置任务优先级**：使用不同优先级区分任务重要性
2. **及时查看即将到期任务**：避免错过重要任务
3. **利用重复任务功能**：对于固定时间的习惯任务，设置重复周期
4. **自定义任务标签**：使用标签功能对任务进行分类
5. **查看消息中心**：及时了解系统提醒和通知
