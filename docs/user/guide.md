# 学习任务微信小程序用户指南

## 📱 应用简介

学习任务微信小程序是一个基于DDD架构的儿童学习习惯培养工具。通过智能任务管理、星星积分系统和奖励兑换机制，帮助小朋友养成良好的学习习惯，培养自律能力。

### 🎯 核心理念
- **习惯养成**：通过重复任务培养良好习惯
- **积极激励**：星星奖励系统提供正向反馈
- **责任培养**：必做任务机制培养责任感
- **家庭教育**：支持家长和小朋友双角色管理

## 👥 用户角色系统

### 角色类型
应用支持两种用户角色：
- **家长角色**：负责任务创建、奖励设置、进度监督
- **小朋友角色**：专注任务完成、星星获取、奖励兑换

### 角色切换操作
1. 点击页面右上角的用户头像
2. 在弹出的用户切换器中选择角色
3. 确认切换后，界面会根据角色权限调整
4. 不同角色看到的功能和数据会有所区别

### 权限说明
| 功能 | 家长角色 | 小朋友角色 |
|------|----------|------------|
| 创建任务 | ✅ | ❌ |
| 编辑任务 | ✅ | ❌ |
| 完成任务 | ✅ | ✅ |
| 查看进度 | ✅ | ✅ |
| 兑换奖励 | ✅ | ✅ |
| 设置奖励 | ✅ | ❌ |
| 查看统计 | ✅ | ✅ |

## 🎯 任务管理系统

### 任务类型详解

#### 📚 学习任务（蓝色主题）
- **用途**：学科学习、作业完成、知识复习
- **特点**：通常有明确的时间要求和完成标准
- **示例**：完成数学作业、背诵古诗、阅读30分钟
- **奖励**：通常给予较高的星星奖励

#### 🌱 习惯任务（绿色主题）
- **用途**：日常习惯养成、生活技能培养
- **特点**：需要长期坚持，适合设置重复周期
- **示例**：早起锻炼、整理房间、刷牙洗脸
- **奖励**：奖励适中，重在坚持

#### 🎨 兴趣任务（橙色主题）
- **用途**：兴趣爱好发展、创意活动
- **特点**：趣味性强，激发小朋友主动性
- **示例**：画画、弹琴、手工制作
- **奖励**：奖励丰富，鼓励探索

### 创建任务流程

#### 基础信息设置
1. **选择任务类型**：根据任务性质选择学习、习惯或兴趣
2. **填写任务标题**：简洁明确的任务描述
3. **设置任务描述**：详细说明任务要求和完成标准
4. **选择截止时间**：设定任务完成的最后期限

#### 高级设置选项
1. **优先级设置**：
   - 🔴 高优先级：重要且紧急的任务
   - 🟡 中优先级：重要但不紧急的任务
   - 🟢 低优先级：可以灵活安排的任务

2. **重复设置**：
   - 每日重复：适合日常习惯
   - 每周重复：适合周期性任务
   - 每月重复：适合月度目标
   - 自定义重复：灵活设置重复周期

3. **星星奖励**：
   - 根据任务难度和重要性设置奖励数量
   - 建议范围：1-5颗星星
   - 必做任务可设置更高奖励

4. **必做任务标记**：
   - 勾选后任务变为必做任务
   - 未完成会扣除相应星星
   - 适合重要的学习任务

### 任务完成操作

#### 标记完成
1. 在任务列表中找到要完成的任务
2. 点击任务右侧的圆形完成按钮
3. 系统自动记录完成时间
4. 立即获得星星奖励并显示奖励动画

#### 完成确认
- 任务完成后状态变为"已完成"
- 完成时间精确到分钟
- 星星奖励立即到账
- 可在任务详情中查看完成记录

## ⭐ 星星积分系统

### 星星获取方式
1. **完成任务**：主要的星星来源
2. **连续完成**：连续完成任务有额外奖励
3. **提前完成**：提前完成任务可能有奖励加成
4. **特殊活动**：节日或特殊活动的额外奖励

### 星星有效期机制

#### 有效期类型
- **永久有效**：特殊奖励或重要成就获得的星星
- **季度有效**：90天有效期，适合长期目标
- **月度有效**：30天有效期，鼓励及时使用
- **周度有效**：7天有效期，促进快速消费

#### FIFO消费策略
系统采用先进先出(FIFO)策略：
1. 优先消费即将过期的星星
2. 自动计算最优消费组合
3. 避免星星浪费，最大化使用效率
4. 在星星详情页可查看消费顺序

### 星星管理功能

#### 星星日历
- 📅 日历视图显示每日星星获得情况
- 🌟 不同颜色表示不同数量的星星
- 📊 点击日期查看详细获得记录
- 📈 月度统计显示获得趋势

#### 星星记录
- **获得记录**：详细记录每次星星获得
- **消费记录**：记录所有星星使用情况
- **过期记录**：显示过期星星的详细信息
- **余额查询**：实时显示当前星星余额

#### 过期提醒
- 星星过期前3天开始提醒
- 消息中心显示过期提醒
- 页面顶部显示过期警告
- 建议及时使用即将过期的星星

## 🎁 奖励兑换系统

### 奖励类型分类

#### 🎮 物品奖励
- **玩具类**：小玩具、文具、书籍
- **零食类**：健康零食、水果、饮料
- **用品类**：学习用品、生活用品
- **特色物品**：根据小朋友兴趣定制

#### 🎪 特权奖励
- **时间特权**：额外游戏时间、看电视时间
- **选择特权**：选择晚餐菜单、周末活动
- **免责特权**：免做某项家务、延迟睡觉
- **陪伴特权**：与家长的专属时间

#### 🎉 活动奖励
- **外出活动**：游乐园、电影院、公园
- **学习活动**：博物馆、科技馆、图书馆
- **社交活动**：与朋友聚会、生日派对
- **体验活动**：手工课、烹饪课、运动课

### 兑换操作流程

#### 浏览奖励
1. 进入"奖池"页面
2. 浏览不同类别的奖励
3. 查看奖励详情和所需星星数量
4. 确认当前星星余额是否足够

#### 执行兑换
1. 选择想要兑换的奖励
2. 点击"兑换"按钮
3. 系统检查星星余额
4. 确认兑换后扣除相应星星
5. 奖励状态变更为"已兑换"

#### 兑换状态管理
- **可兑换**：满足兑换条件的奖励
- **已兑换**：已经兑换但未领取的奖励
- **已领取**：已经实际获得的奖励
- **已禁用**：暂时不可兑换的奖励

### 库存管理
- **有限奖励**：数量有限，先到先得
- **无限奖励**：可重复兑换的奖励
- **库存提醒**：库存不足时的提醒
- **补货通知**：新奖励上架的通知

## 💡 使用技巧和建议

### 任务管理技巧
1. **合理设置优先级**：重要紧急的任务设为高优先级
2. **善用重复任务**：日常习惯设置为重复任务
3. **适度设置必做任务**：避免过多必做任务造成压力
4. **及时调整任务**：根据实际情况灵活调整任务安排

### 星星管理建议
1. **关注有效期**：及时使用即将过期的星星
2. **合理消费**：平衡即时满足和长期目标
3. **查看消费记录**：了解星星使用习惯
4. **设定消费目标**：为特定奖励制定星星储蓄计划

### 奖励设置原则
1. **奖励多样化**：物品、特权、活动相结合
2. **价值匹配**：奖励价值与所需星星数量匹配
3. **及时更新**：定期更新奖励内容保持新鲜感
4. **个性化定制**：根据小朋友兴趣设置专属奖励

### 家庭使用建议
1. **角色分工明确**：家长负责设置，小朋友专注完成
2. **定期回顾**：每周回顾任务完成情况和改进点
3. **正向激励**：多使用鼓励和表扬，少用惩罚
4. **循序渐进**：从简单任务开始，逐步增加难度

## ❓ 常见问题快速解答

### 任务相关
**Q: 如何修改已创建的任务？**
A: 家长角色可以在任务详情页面点击"编辑"按钮进行修改。

**Q: 任务完成后可以撤销吗？**
A: 可以，在任务详情页面点击"撤销完成"，但已获得的星星会被扣回。

**Q: 重复任务如何管理？**
A: 重复任务会自动创建新的任务实例，可以在任务设置中修改重复规则。

### 星星相关
**Q: 星星过期了怎么办？**
A: 过期的星星无法恢复，建议关注过期提醒及时使用。

**Q: 如何查看星星的详细记录？**
A: 在星星页面点击"详细记录"可以查看所有获得、消费、过期记录。

### 奖励相关
**Q: 兑换的奖励如何领取？**
A: 兑换成功后，家长会收到通知，线下兑现承诺的奖励。

**Q: 可以取消已兑换的奖励吗？**
A: 已兑换的奖励通常不能取消，请谨慎选择。
