# 后端部署小白指引

> **适用场景**：微信小程序开发者工具中运行，需要将后端部署到远程服务器
> **当前状态**：前端连接localhost:3000（本地），需要改为远程服务器
> **难度等级**：⭐ 新手友好

---

## 🌟 一分钟理解后端部署

### 什么是后端部署？
```
当前状态：
┌─────────────┐
│ 微信小程序    │ 连接
│ 开发者工具    │─────▶ localhost:3000 (你的电脑)
│              │
│              │
│  后端代码    │ 运行在你的电脑上
└─────────────┘

部署后状态：
┌─────────────┐      🌐 互联网
│ 微信小程序    │ 连接
│ 开发者工具    │─────▶ your-server.com:3000 (远程服务器)
│              │
│              │
│  后端代码    │ 运行在远程服务器上
└─────────────┘
```

### 为什么要部署？
1. ✅ **真机测试**：手机无法访问你电脑的localhost
2. ✅ **随时随地测试**：不在电脑前也能测试
3. ✅ **真实网络环境**：测试真实网络延迟和错误
4. ✅ **多人协作**：其他人也能访问测试环境

## 🎯 方案1：内网穿透（5分钟开始测试）⭐⭐⭐⭐⭐

### 适用场景
- ✅ 快速开始测试
- ✅ 不想花钱买服务器
- ✅ 只需要你电脑开机

### 步骤1：获取外网访问地址

#### 选项A：使用Ngrok（推荐新手）
1. **下载Ngrok**
   - 访问：https://ngrok.com
   - 注册账号（免费）
   - 下载对应系统版本（macOS/Windows/Linux）

2. **启动Ngrok**
   ```bash
   # macOS/Linux用户
   cd /Users/你的用户名/downloads
   unzip ngrok-v3-stable-darwin-amd64.zip
   chmod +x ngrok
   ./ngrok http 3000
   ```

3. **获取公网地址**
   - 终端会显示类似：
   ```
   Forwarding
   http://abc123.ngrok.io -> http://localhost:3000
   ```

4. **复制公网地址**
   - 记住这个地址：`http://abc123.ngrok.io`

#### 选项B：使用LocalTunnel（更简单）
1. **安装工具**
   ```bash
   npm install -g localtunnel
   ```

2. **启动隧道**
   ```bash
   lt --port 3000
   ```

3. **获取公网地址**
   - 终端会显示：`your url is: https://random-name.loca.lt`

---

### 步骤2：修改微信小程序配置

#### 推荐方式：预置运行时环境配置
1. 打开微信开发者工具
2. 进入 Console
3. 执行以下代码（把地址替换成你的 Ngrok / LocalTunnel 地址）：
   ```javascript
   wx.setStorageSync('ENABLE_API', 'true');
   wx.setStorageSync('API_BASE_URL', 'http://abc123.ngrok.io');
   ```
4. 点击“清缓存” -> “清除全部缓存”
5. 重新点击“编译”

#### 说明
- 当前版本不再依赖修改 `utils/api-config.js` 或 `app.js` 来切环境
- 若未显式写入 `ENABLE_API=true` 和 `API_BASE_URL`，应用会保持本地模式
- Ngrok 地址每次重启可能变化，变化后只需要重新写一次存储配置

---

### 步骤3：测试连接

#### 验证步骤
1. 打开微信开发者工具控制台
2. 查看日志，应该看到：
   ```
   ✅ 保留用户配置的API模式: true
   ✅ 保留用户配置的API地址: http://abc123.ngrok.io
   ```

3. 尝试登录，看是否能成功连接

#### 常见问题
**问题1：连接超时**
- 检查Ngrok是否还在运行
- 检查终端是否有报错

**问题2：Ngrok地址变化**
- 每次重启Ngrok会生成新地址
- 需要重新修改小程序配置

**问题3：端口被占用**
```bash
# 查看哪个程序占用了3000端口（macOS）
lsof -i :3000

# 杀掉占用的进程（根据PID）
kill -9 <PID>

# 或更改后端使用其他端口，如3001
```

### 部署步骤（以Railway为例）

#### 步骤1：准备后端代码
```bash
# 在项目根目录执行
cd backend

# 确认依赖已安装
npm install

# 测试本地运行是否正常
node server.js
```

#### 步骤2：连接Railway
1. 访问 https://railway.app
2. 使用GitHub账号登录
3. 点击右上角 "+ New Project"

#### 步骤3：创建新服务
1. **选择模板**
   - 可以选择"Node.js"模板
   - 或选择"Empty Service"

2. **配置服务**
   - **Project Name**: `study-task-backend`
   - **Environment**: `Node 18.x`
   - **Region**: 选择离你最近的（如Singapore）

#### 步骤4：部署代码
有三种方式：

**方式A：从GitHub连接（最简单）**
1. 点击"Connect GitHub"
2. 选择你的GitHub仓库
3. 选择分支：`milestone-05-test`
4. 点击"Connect"
5. Railway会自动部署

**方式B：上传代码**
1. 在"Settings"中选择"Root Directory"
2. 设置为：`/`
3. Railway会部署整个后端目录

**方式C：部署为Docker（需要Dockerfile）**
- 需要先创建Dockerfile（稍后说明）

#### 步骤5：获取服务器地址
1. 部署完成后，Railway会生成一个URL
2. 例如：`https://study-task-backend-production.up.railway.app`
3. 复制这个地址

---

### 步骤6：配置环境变量

1. 在Railway项目页面点击"Variables"
2. 添加以下环境变量：
   ```
   NODE_ENV=production
   JWT_SECRET=你的随机密钥（必须设置！）
   ```

3. 如何生成JWT_SECRET：
   ```bash
   # 在终端执行（生成32位随机字符串）
   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
   ```

4. 复制生成的密钥，粘贴到Railway

#### 步骤7：配置数据库（可选）

Railway提供免费PostgreSQL数据库：

1. 在项目页面点击"New Database"
2. 数据库名称：`studytaskdb`
3. 选择PostgreSQL 14.2
4. 部署后，Railway会提供：
   - Database URL
   - Username
   - Password
   - Database Name

5. 修改后端代码使用PostgreSQL（需要修改数据库连接代码）

---

### 步骤8：修改小程序配置

#### 预置运行时配置
```javascript
wx.setStorageSync('ENABLE_API', 'true');
wx.setStorageSync('API_BASE_URL', 'https://study-task-backend-production.up.railway.app');
```

#### 在开发者工具中重新编译

- 写入后执行“清缓存” -> “清除全部缓存”
- 再点击“编译”

---

### 步骤9：验证部署

#### 测试步骤
1. 真机中打开小程序
2. 尝试登录
3. 检查微信开发者工具控制台，应该显示网络请求

#### 如何查看Railway日志
1. 在Railway项目页面
2. 点击"Logs"标签
3. 实时查看后端运行日志

## 🔥 方案3：阿里云/腾讯云（30分钟，适合长期）

### 阿里云轻量应用服务器

#### 步骤1：购买服务器
1. 访问：https://www.aliyun.com/product/ecs
2. 选择"轻量应用服务器"
3. 推荐配置：
   - **地域**：华东1（杭州）
   - **实例规格**：1核2GB（最便宜）
   - **镜像**：Ubuntu 20.04
   - **带宽**：3Mbps（测试足够）
   - **价格**：约¥60/年（可按月¥6）

#### 步骤2：创建实例
1. 点击"立即购买"
2. 等待1-3分钟创建完成
3. 实例创建后会显示公网IP地址

#### 步骤3：远程连接服务器
```bash
# 在本地终端执行
ssh root@你的公网IP

# 首次登录会提示修改密码（在控制台查看）
```

#### 步骤4：安装Node.js和MySQL
```bash
# 更新系统
apt update
apt install -y curl

# 安装Node.js 18.x
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -

# 安装MySQL 5.7
apt install -y mysql-server mysql-client libmysqlclient-dev

# 启动MySQL
systemctl start mysql

# 设置root密码（重要！）
mysql -u root
ALTER USER 'root'@'localhost' IDENTIFIED BY '你的密码';
```

#### 步骤5：上传代码
```bash
# 在本地（你的电脑）执行
cd backend
scp -r . root@服务器公网IP:/root/study-task-backend
```

#### 步骤6：在服务器上配置
```bash
# 在服务器上执行
cd /root/study-task-backend

# 安装依赖
npm install

# 配置环境变量
export NODE_ENV=production
export JWT_SECRET=你的随机密钥
export DB_HOST=localhost
export DB_USER=root
export DB_PASSWORD=你的MySQL密码
export DB_NAME=task_wechat

# 测试运行
node server.js
```

#### 步骤7：使用PM2保持后端运行
```bash
# 安装PM2（进程管理器）
npm install -g pm2

# 启动后端
pm2 start server.js --name study-task-backend

# 查看运行状态
pm2 status

# 查看日志
pm2 logs study-task-backend

# 设置开机自启
pm2 startup
pm2 save
```

#### 步骤8：配置安全组（重要！）
1. 在阿里云控制台找到你的实例
2. 点击"安全组"
3. 添加入方向规则：
   - 协议：TCP
   - 端口范围：3000-3010
   - 授权对象：0.0.0.0/0（允许所有IP）
4. 点击"确定"

## 🚨 重要提醒

### 关于HTTPS
- 微信小程序要求HTTPS
- Ngrok：自动提供HTTPS
- Railway：自动提供HTTPS
- 阿里云：需要配置SSL证书（免费Let's Encrypt）

### 关于数据持久化
- Ngrok：重启后数据丢失
- Railway：提供数据库服务，数据持久
- 阿里云：自行管理数据持久化

### 关于域名（可选）
- 可以购买域名配置到服务器
- 小程序可以配置为白名单域名
- 免费服务器会分配随机子域名

## 🆘 遇到问题怎么办？

### 问题1：连接不上后端

**排查清单**：
- [ ] Ngrok是否还在运行？
- [ ] 后端进程是否存活？
- [ ] 小程序配置的地址是否正确？
- [ ] 安全组/防火墙是否开放端口？

### 问题2：登录失败

**排查清单**：
- [ ] 后端JWT_SECRET是否正确配置？
- [ ] 数据库是否正确连接？
- [ ] 后端日志有什么错误信息？

### 问题3：操作很慢

**优化建议**：
- 使用Ping测试网络延迟
- 检查服务器配置是否够用
- 考虑更换服务器地域
