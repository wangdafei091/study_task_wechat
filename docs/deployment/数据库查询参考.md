## 任务表查询

### 1. 查看最近10个任务
```bash
mysql -u root -p -e "USE task_wechat; SELECT task_id, title, type, date, status, points, created_at FROM tasks ORDER BY created_at DESC LIMIT 10;"
```

### 2. 查看今天的任务
```bash
mysql -u root -p -e "USE task_wechat; SELECT task_id, title, type, date, status, points FROM tasks WHERE date = CURDATE();"
```

### 3. 查看某个用户的任务
```bash
# 先获取用户ID
mysql -u root -p -e "USE task_wechat; SELECT user_id, username FROM users;"

# 替换 USER_ID 为实际的用户ID
mysql -u root -p -e "USE task_wechat; SELECT * FROM tasks WHERE user_id = 'USER_ID' ORDER BY created_at DESC;"
```

### 4. 查看未完成的任务
```bash
mysql -u root -p -e "USE task_wechat; SELECT task_id, title, type, date, status FROM tasks WHERE status = 0 ORDER BY date ASC;"
```

### 5. 统计任务数量
```bash
mysql -u root -p -e "USE task_wechat; SELECT status, COUNT(*) as count FROM tasks GROUP BY status;"
```

### 6. 查看任务表结构
```bash
mysql -u root -p -e "DESC task_wechat.tasks;"
```

## 组合查询

### 1. 查看每个用户的任务统计
```bash
mysql -u root -p -e "USE task_wechat;
SELECT u.username, COUNT(t.task_id) as task_count, SUM(t.points) as total_points
FROM users u
LEFT JOIN tasks t ON u.user_id = t.user_id
GROUP BY u.user_id, u.username;"
```

### 2. 查看今日完成情况
```bash
mysql -u root -p -e "USE task_wechat;
SELECT date, status, COUNT(*) as count
FROM tasks
WHERE date >= CURDATE() - INTERVAL 7 DAY
GROUP BY date, status
ORDER BY date DESC;"
```

## 常用操作

### 备份数据库
```bash
mysqldump -u root -p task_wechat > backup_task_wechat_$(date +%Y%m%d_%H%M%S).sql
```

### 恢复数据库
```bash
mysql -u root -p task_wechat < backup_task_wechat_20260312_133000.sql
```

### 清空所有任务（危险操作！）
```bash
mysql -u root -p -e "USE task_wechat; DELETE FROM tasks;"
```

### 删除特定任务
```bash
# 替换 TASK_ID 为实际的任务ID
mysql -u root -p -e "USE task_wechat; DELETE FROM tasks WHERE task_id = 'TASK_ID';"
```

## 表结构参考

### tasks 表
```sql
CREATE TABLE tasks (
    task_id VARCHAR(36) PRIMARY KEY,           -- 任务ID，UUID
    user_id VARCHAR(36) NOT NULL,             -- 用户ID
    title VARCHAR(200) NOT NULL,              -- 任务标题
    description TEXT,                          -- 任务描述
    type VARCHAR(20) NOT NULL,                -- 类型：study/habit/interest
    date DATE NOT NULL,                       -- 任务日期
    startTime VARCHAR(10),                     -- 开始时间 HH:mm
    endTime VARCHAR(10),                      -- 结束时间 HH:mm
    points INT NOT NULL DEFAULT 0,             -- 奖励星星数
    pointsExpiry VARCHAR(20) NOT NULL,        -- 有效期类型：permanent/week/month/quarter
    isRequired BOOLEAN DEFAULT FALSE,           -- 是否必做任务
    status INT DEFAULT 0,                      -- 状态：0=未完成，1=已完成
    `repeat` JSON,                           -- 重复配置
    isAllDay BOOLEAN DEFAULT FALSE,            -- 是否全天任务
    penaltyApplied BOOLEAN DEFAULT FALSE,        -- 是否已应用惩罚
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, -- 创建时间
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP -- 更新时间
);
```

### users 表
```sql
CREATE TABLE users (
    user_id VARCHAR(36) PRIMARY KEY,         -- 用户ID，UUID
    username VARCHAR(50) NOT NULL,            -- 用户名
    password VARCHAR(255),                    -- 密码
    openid VARCHAR(100) UNIQUE,               -- 微信openid
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, -- 创建时间
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP -- 更新时间
);
```

## 常见问题

### Q: 查询时报错 "Unknown column 'id'"
**A**: 使用 `task_id` 而不是 `id`，tasks表的主键是 `task_id`。

### Q: 找不到任务表
**A**: 确保使用正确的数据库名 `task_wechat`，不是 `study_task_wechat`。

### Q: 如何查看表是否存在
```bash
mysql -u root -p -e "USE task_wechat; SHOW TABLES;"
```

### Q: 如何查看表的索引
```bash
mysql -u root -p -e "USE task_wechat; SHOW INDEX FROM tasks;"
```

---

## 索引信息

### tasks 表索引
- `PRIMARY`: `task_id`
- `idx_user_date`: `(user_id, date)` - 优化按用户和日期查询
- `idx_user_status`: `(user_id, status)` - 优化按用户和状态查询

### users 表索引
- `PRIMARY`: `user_id`
- `openid`: `openid` - 唯一索引
