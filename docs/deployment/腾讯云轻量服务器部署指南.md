# 腾讯云轻量服务器部署指南

> **目标**：将后端milestone-05-test分支部署到您的腾讯云轻量服务器
> **难度等级**：⭐⭐ 中等（已有服务器，只需部署）

1. 访问：https://console.cloud.tencent.com/lighthouse/instance/index

## 🚀 第二步：连接到服务器

### macOS/Linux系统
打开终端，执行：

```bash
# 替换为您的实际IP地址
ssh root@your-server-ip

# 首次登录会提示修改密码
# 输入您设置的root密码或SSH密钥
```

### Windows系统
推荐使用PowerShell或安装Git Bash/WSL：

```powershell
# PowerShell
ssh root@your-server-ip

# 或使用Git Bash
ssh root@your-server-ip
```

### 连接成功后
终端提示会从本地变为远程服务器：
```
root@your-server-name:~#
```

## 📦 第三步：服务器环境准备

### 3.1 更新系统
```bash
# 在服务器上执行
apt update && apt upgrade -y

# 安装必要工具
apt install -y curl wget git vim nodejs npm

# 查看Node.js版本
node -v
# 应该显示 v18.x 或更高
```

### 3.2 安装MySQL 5.7
```bash
# 添加MySQL APT仓库（Ubuntu 20.04需要）
wget https://dev.mysql.com/get/mysql-apt-config_0.8.22-1_all.deb -O mysql-apt-config.deb
sudo dpkg -i mysql-apt-config.deb
sudo apt update
apt install -y mysql-server mysql-client libmysqlclient-dev

# 启动MySQL服务
systemctl start mysql
systemctl enable mysql

# 查看MySQL状态
systemctl status mysql

# 设置root密码（重要！）
mysql -u root
```
在MySQL命令行中执行：
```sql
ALTER USER 'root'@'localhost' IDENTIFIED BY 'your-password';
FLUSH PRIVILEGES;
EXIT;
```

### 3.3 创建数据库
```bash
# 登录MySQL
mysql -u root -p

# 创建数据库
CREATE DATABASE task_wechat;

# 使用数据库
USE task_wechat;

# 查看创建结果
SHOW DATABASES;
EXIT;
```

### 3.4 配置防火墙（重要！）
```bash
# 开放必要端口
ufw allow 22      # SSH
ufw allow 80      # HTTP（可选）
ufw allow 443     # HTTPS（可选）
ufw allow 3000    # 后端API端口（必须！）

# 查看防火墙状态
ufw status

# 重新加载防火墙
ufw reload
```

```bash

mkdir -p /root/study-task-backend
cd /root/study-task-backend
```

```bash

```

## 🔧 第五步：配置后端环境

### 5.1 配置环境变量

**方法1：使用.env文件（推荐）**
```bash
cd /root/study-task-backend

# 创建.env文件
cat > .env << 'EOF'
# 数据库配置
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your-mysql-password
DB_NAME=task_wechat

# JWT配置（必须！）
NODE_ENV=production
JWT_SECRET=your-very-long-random-secret-key-32-chars-or-more

# 可选：日志级别
LOG_LEVEL=info
EOF

# 查看创建的文件
cat .env
```

**生成JWT密钥**（在本地终端执行）：
```bash
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
# 输出示例：a1b2c3d4e5f678901234567890abcdef1234567890abcdef
```

### 5.2 创建数据库表
```bash
# 执行数据库迁移
mysql -u root -p task_wechat < database/migrations/001_create_users.sql
mysql -u root -p task_wechat < database/migrations/002_create_tasks.sql

# 验证表创建
mysql -u root -p task_wechat -e "SHOW TABLES;"
```

## 🚀 第六步：启动后端服务

### 6.1 首次启动

## 🔧 第十步：配置开机自启（可选但推荐）

### 10.1 使用PM2配置开机自启
```bash
# 在服务器上执行
pm2 startup

# 保存配置
pm2 save

# 查看启动列表
pm2 list
```

### 10.2 创建systemd服务（更稳定）

**创建服务文件**：
```bash
sudo vim /etc/systemd/systemd/study-task-backend.service
```

粘贴以下内容：
```ini
[Unit]
Description=Study Task Backend Service
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/study-task-backend
ExecStart=/usr/bin/node /root/study-task-backend/server.js
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

保存并退出vim（:wq然后回车）

**启用服务**：
```bash
# 重载systemd配置
sudo systemctl daemon-reload

# 启用服务
sudo systemctl enable study-task-backend

# 启动服务
sudo systemctl start study-task-backend

# 查看状态
sudo systemctl status study-task-backend

# 查看日志
sudo journalctl -u study-task-backend -f
```

## 🚨 常见问题排查

### 问题1：连接不上服务器

**可能原因**：
- 服务器防火墙未开放SSH端口
- 服务器IP地址变化
- 服务器未启动

**排查步骤**：
```bash
# 1. Ping服务器
ping your-server-ip

# 2. 检查SSH端口（云控制台查看安全组规则）
# 在腾讯云控制台：安全组 → 添加规则 → 协议TCP → 端口22 → 源0.0.0.0/0 → 允许

# 3. 尝试不同用户登录
# ssh root@your-server-ip
```

### 问题2：MySQL连接失败

**可能原因**：
- MySQL服务未启动
- 密码错误
- 权限问题

**排查步骤**：
```bash
# 检查MySQL状态
systemctl status mysql

# 如果未启动，启动它
systemctl start mysql

# 检查MySQL进程
ps aux | grep mysql

# 测试MySQL连接
mysql -u root -p -e "SELECT 1;"
```

### 问题3：后端服务启动失败

**可能原因**：
- 端口被占用
- 数据库连接失败
- JWT_SECRET未设置

**排查步骤**：
```bash
# 1. 查看后端日志
pm2 logs study-task-backend

# 2. 查看端口占用
netstat -tlnp | grep 3000

# 3. 杀掉占用端口的进程（如果有）
kill -9 <PID>

# 4. 检查.env文件
cat .env

# 5. 手动测试运行
node server.js
```

### 问题4：微信小程序无法连接

**可能原因**：
- 小程序配置的地址不正确
- 防火墙未开放3000端口
- 后端服务未启动

**排查步骤**：
```bash
# 1. 在服务器检查服务状态
pm2 status study-task-backend

# 2. 在本地测试连接
curl http://your-server-ip:3000/health

# 3. 检查腾讯云安全组
# 控制台 → 实例 → 安全组 → 添加规则
# 协议：TCP
# 端口：3000
# 源：0.0.0.0/0
# 策略：允许

# 4. 重启防火墙
ufw reload
```

### 问题5：数据库操作失败

**排查步骤**：
```bash
# 1. 登录MySQL
mysql -u root -p

# 2. 检查数据库
USE task_wechat;
SHOW TABLES;

# 3. 检查数据
SELECT COUNT(*) FROM users;
SELECT COUNT(*) FROM tasks;

# 4. 查看最近错误日志
tail -n 100 backend.log | grep ERROR
```

## 📊 性能优化建议

### 1. 使用Nginx反向代理（可选）
```bash
# 安装Nginx
apt install -y nginx

# 配置Nginx
sudo vim /etc/nginx/sites-available/study-task-backend

# 配置内容：
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}

# 启用配置
sudo ln -s /etc/nginx/sites-available/study-task-backend /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### 2. 启用Gzip压缩（推荐）
在Nginx配置中添加：
```nginx
gzip on;
gzip_types text/plain application/json application/javascript text/css application/xml;
gzip_min_length 1000;
```

### 3. 数据库优化
```sql
-- 在MySQL中添加索引
CREATE INDEX idx_user_id ON tasks(user_id);
CREATE INDEX idx_created_at ON tasks(created_at);
CREATE INDEX idx_status ON tasks(status);
```

## 🔒 安全加固建议

### 1. 配置防火墙规则
```bash
# 只开放必要端口
ufw default deny incoming
ufw allow 22      # SSH
ufw allow 80      # HTTP
ufw allow 443     # HTTPS
ufw allow 3000    # 后端API
ufw enable

# 查看状态
ufw status numbered
```

### 2. 配置fail2ban防暴力破解
```bash
# 安装fail2ban
apt install -y fail2ban

# 配置SSH防护
sudo vim /etc/fail2ban/jail.local

# 添加规则：
[sshd]
enabled = true
port = ssh
filter = sshd
logpath = /var/log/auth.log
maxretry = 5
bantime = 600
findtime = 600
```

### 3. 定期备份数据库
```bash
# 创建备份脚本
cat > /root/backup-db.sh << 'EOF'
#!/bin/bash
DATE=$(date +%Y%m%d_%H%M%S)
mysqldump -u root -p task_wechat > /root/backups/task_$DATE.sql
find /root/backups -mtime +7 -delete
EOF

chmod +x /root/backup-db.sh

# 添加定时任务（每天凌晨3点备份）
crontab -e
0 3 * * * /root/backup-db.sh
```
