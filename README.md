# 学习任务微信小程序

## 项目介绍
学习任务微信小程序是一个帮助小朋友养成良好学习习惯的任务管理工具。通过简洁的界面和丰富的功能，帮助小朋友更好地规划和管理自己的学习任务。

## 主要功能
- 任务创建和管理
- 支持多种任务类型（学习、习惯、兴趣）
- 任务完成度跟踪
- 任务重复设置
- 任务分布热力图
- 任务进度统计分析
- 奖励机制
- 消息提醒
- 积分有效期管理（自然周期/月/季/年）
- 必做任务标记和处理
- 批量处理任务记录
- 星星分组与"先过期先使用"消费策略

## 最新功能：星星有效期和消费机制

### 星星分组管理
- 按过期时间将星星分组存储
- 实现"先过期先使用"的消费策略
- 自动清理过期星星
- 数据一致性检查机制

### 实现原理
1. 每次任务完成时，根据设置的有效期类型计算星星过期时间
2. 将获得的星星添加到对应过期时间的星星分组中
3. 消费星星时，优先使用即将过期的星星
4. 定期清理已过期的星星，确保数据一致性

### 过期预测功能
- 基于星星分组数据计算未来星星过期趋势
- 提供可视化图表展示过期预测
- 帮助用户合理规划星星使用

## 日志规范
为便于追踪和调试，在关键位置添加日志。使用 `logger` 工具统一格式，例如：

```javascript
const logger = require('../../utils/logger');

// 记录普通信息
logger.log('componentName', '操作描述', 变量);

// 记录流程节点信息
logger.info('componentName', '重要流程点', 变量);

// 记录警告信息
logger.warn('componentName', '警告描述', 变量);

// 记录错误信息 
logger.error('componentName', '错误描述', 错误对象);
```

### 日志记录要点
1. **关键点必须添加日志**：
   - 任务创建、编辑、删除和状态变更
   - 重要数据的读取和存储操作
   - 页面重要生命周期事件
   - 用户关键操作
   - 异步操作的开始和结束
   - 所有积分计算和有效期处理过程

2. **日志内容要求**：
   - 保持简洁明了，包含必要信息
   - 对象日志使用精简版，仅记录关键字段
   - 记录操作类型、对象ID和关键参数
   - 错误日志需包含错误详情和上下文
   - 批量处理操作记录当前进度

3. **避免过度日志**：
   - 不记录频繁重复的常规操作
   - 不记录大量无关紧要的信息
   - 循环中谨慎使用日志
   - 过大对象使用精简版记录关键属性
