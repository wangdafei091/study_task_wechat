# 学习任务微信小程序

## 项目介绍
学习任务微信小程序是一个帮助小朋友养成良好学习习惯的任务管理工具。通过简洁的界面和丰富的功能，帮助小朋友更好地规划和管理自己的学习任务。

## 主要功能
- 任务创建和管理
- 支持多种任务类型（学习、习惯、兴趣）
- 任务完成度跟踪
- 任务重复设置
- 任务分布热力图
- 任务进度统计分析
- 奖励机制
- 消息提醒

## 项目结构
项目采用微信小程序原生框架开发，主要目录结构如下：

```
study_task_wechat/
├── app.js                  # 小程序入口文件
├── app.json                # 小程序全局配置
├── app.wxss                # 小程序全局样式
├── components/             # 组件目录
│   ├── card/               # 卡片容器组件
│   ├── progressRing/       # 环形进度条组件
│   ├── progressBar/        # 进度条组件
│   ├── taskItem/           # 任务项组件
│   ├── task-heatmap/       # 任务热力图组件
│   ├── float-menu/         # 浮动菜单组件
│   └── template-selector/  # 模板选择器组件
├── pages/                  # 页面目录
│   ├── index/              # 主页（任务日历）
│   ├── task/               # 任务详情页
│   ├── task-edit/          # 任务编辑页
│   ├── rewards/            # 奖池页面
│   └── message/            # 消息中心
├── utils/                  # 工具函数目录
│   ├── taskManager.js      # 任务管理工具
│   ├── dateUtils.js        # 日期处理工具
│   ├── taskUtils.js        # 任务处理工具
│   └── uiUtils.js          # UI辅助工具
└── assets/                 # 静态资源目录
```

## 开发规范

### 命名规范
- 组件名称：小驼峰命名法，如 `taskItem`、`progressRing`
- 工具函数：小驼峰命名法，如 `formatDate`、`showLoading`
- 常量：全大写下划线分隔，如 `MAX_TASK_COUNT`、`DEFAULT_DURATION`

### UI规范
- 颜色系统
  - 学习任务：#4285F4（蓝色）
  - 习惯任务：#4CAF50（绿色）
  - 兴趣任务：#FF9800（橙色）
  - 背景色：#F6F8FA
  - 卡片背景：#FFFFFF
  - 文本主色：#333333
  - 辅助文本：#666666
  - 次要文本：#999999

- 尺寸规范
  - 按钮高度：90rpx
  - 输入框高度：90rpx
  - 卡片内边距：30rpx
  - 元素间距：12rpx/24rpx
  - 功能按钮圆角：8rpx
  - 卡片容器圆角：16rpx

## 技术栈
- 微信小程序原生开发
- 微信基础库 >= 2.19.0
- ES6+
- WXSS

## 开发环境
