# 学习任务微信小程序

## 项目简介

学习任务微信小程序是一个专为帮助小朋友养成良好学习习惯而设计的任务管理工具。通过简洁的界面和丰富的功能，帮助小朋友更好地规划和管理自己的学习任务。

## 主要功能

1. **任务管理**
   - 创建和编辑任务
   - 设置任务类型（习惯/学习）
   - 设置任务时间
   - 任务完成状态跟踪

2. **进度跟踪**
   - 习惯养成进度
   - 学习任务进度
   - 兴趣培养进度
   - 可视化进度展示

3. **统计分析**
   - 任务完成率统计
   - 任务类型分布
   - 连续完成天数记录
   - 历史数据查看

4. **奖励系统**
   - 任务完成奖励
   - 连续打卡奖励
   - 奖励进度跟踪
   - 奖励解锁记录

5. **消息通知**
   - 任务提醒
   - 奖励通知
   - 系统消息
   - 消息中心管理

## 任务类型说明

### 当前支持的任务类型

1. **习惯类任务（⏰）**
   - 包括日常生活习惯和兴趣爱好
   - 默认持续时间：10分钟
   - 支持重复设置

2. **学习类任务（📝）**
   - 包括各类学习任务
   - 默认持续时间：60分钟
   - 支持上传作业照片

### 任务类型变更历史

- 2024-04-01：将"整理收纳"类型合并到"习惯"类型中
- 2024-04-01：将"整理收纳圆环"更名为"兴趣圆环"
