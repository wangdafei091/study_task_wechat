# 学习任务微信小程序

## 项目简介

学习任务微信小程序是一个专为帮助小朋友养成良好学习习惯而设计的任务管理工具。通过简洁的界面和丰富的功能，帮助小朋友更好地规划和管理自己的学习任务。系统采用组件化设计，支持多种任务类型，提供丰富的进度跟踪和奖励机制。

## 主要功能

1. **任务管理**
   - 创建和编辑任务
   - 设置任务类型（习惯/学习）
   - 设置任务时间
   - 任务完成状态跟踪
   - 支持重复任务设置
   - 任务优先级管理

2. **进度跟踪**
   - 习惯养成进度
   - 学习任务进度
   - 兴趣培养进度
   - 可视化进度展示
   - 支持多种进度展示方式（圆环/进度条）
   - 实时进度更新

3. **统计分析**
   - 任务完成率统计
   - 任务类型分布
   - 连续完成天数记录
   - 历史数据查看
   - 自定义统计周期
   - 数据可视化展示

4. **奖励系统**
   - 任务完成奖励
   - 连续打卡奖励
   - 奖励进度跟踪
   - 奖励解锁记录
   - 多级奖励机制
   - 奖励兑换系统

5. **消息通知**
   - 任务提醒
   - 奖励通知
   - 系统消息
   - 消息中心管理
   - 消息分类展示
   - 消息状态管理

## 任务类型说明

### 当前支持的任务类型

1. **习惯类任务（⏰）**
   - 包括日常生活习惯和兴趣爱好
   - 默认持续时间：10分钟
   - 支持重复设置
   - 支持自定义提醒
   - 支持进度追踪
   - 支持完成记录

2. **学习类任务（📝）**
   - 包括各类学习任务
   - 默认持续时间：60分钟
   - 支持上传作业照片
   - 支持任务分类
   - 支持难度设置
   - 支持学习记录

## 开发规范

1. **代码规范**
   - 使用ES6+语法
   - 遵循微信小程序开发规范
   - 统一的代码格式化
   - 使用ESLint进行代码检查
   - 遵循Airbnb JavaScript规范
   - 使用Prettier进行代码格式化

2. **命名规范**
   - 文件命名：小写字母，连字符分隔
   - 变量命名：驼峰式
   - 组件命名：大驼峰式
   - 常量命名：全大写，下划线分隔
   - 私有方法命名：下划线前缀
   - 事件命名：on前缀

3. **注释规范**
   - 必要的代码注释
   - 清晰的函数说明
   - 版本更新记录
   - 使用JSDoc格式
   - 复杂逻辑说明
   - 重要变更记录
