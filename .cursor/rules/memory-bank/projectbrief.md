# 微信小程序学习任务应用

## 项目概述

这是一个专为小朋友设计的任务管理小程序，重点在于帮助他们养成良好的学习习惯和时间管理能力。应用具有简洁友好的界面，丰富的任务管理功能和有趣的激励机制。

## 核心功能

- 多类型任务管理（学习任务、习惯培养、兴趣发展）
- 任务创建、编辑、删除和状态更新
- 任务完成度进度跟踪
- 任务重复设置（每日、每周等）
- 任务分布热力图
- 任务进度统计分析
- 奖励积分机制和有效期管理
- 必做任务特殊处理
- 消息提醒系统

## 主要用户群体

- 小学生（6-12岁）：作为主要使用者，记录和完成学习任务
- 家长：作为辅助监督者，帮助孩子设置和跟踪任务

## 产品价值主张

- 培养孩子自律性和时间管理能力
- 提高学习任务的完成率和质量
- 建立习惯养成的正向反馈循环
- 激发孩子的学习兴趣和成就感
- 提供直观的进度和成果可视化
- 强化家长与孩子的互动协作

## 设计原则

- **简洁明了**：界面设计简单清晰，避免复杂操作
- **视觉引导**：通过色彩和图形元素增强用户体验
- **积极反馈**：提供及时的积极反馈，激励持续使用
- **成长记录**：记录孩子的进步和成长轨迹
- **适应性**：适应不同场景和使用需求
- **安全稳定**：确保数据安全和操作可靠性

## 技术架构

应用基于微信小程序原生开发，采用组件化和模块化的设计理念。主要技术特点包括：

- 组件封装：将UI元素和功能逻辑封装为可复用组件
- 事件驱动：使用事件机制实现组件间通信
- 数据管理：使用全局状态和本地存储管理数据
- 工具分离：将通用功能抽象为工具模块
- 性能优化：采用增量更新和懒加载策略
- 适配支持：兼容不同设备尺寸和屏幕方向

## 核心组件
1. 进度环组件 (progressRing)
   - 功能：圆环形进度显示
   - 特点：支持多种任务类型样式
   - 接口：输入进度百分比和类型，输出点击事件
   - 样式：支持default/habit/study/interest样式
   - 交互：点击事件，动画效果
   - 性能优化：渲染性能提升计划中

2. 任务热力图组件 (task-heatmap)
   - 功能：以热力图形式展示任务分布情况
   - 特点：支持月份导航、直观展示任务密度
   - 接口：输入任务数据，输出月份变更和日期选择事件
   - 样式：蓝色渐变热力展示，清晰的日历网格
   - 交互：点击日期查看当日任务，编辑任务信息
   - 编辑功能：支持修改任务积分和描述，支持循环任务编辑范围选择
   - 优化点：减少垂直空间占用，优化任务项UI，增强视觉效果

3. 进度条组件 (progressBar)
   - 功能：线性进度展示
   - 特点：支持多种样式和主题
   - 接口：输入进度百分比和类型，输出点击事件
   - 样式：支持default/habit/study/interest样式
   - 交互：点击事件，动画效果

4. 卡片容器组件 (card)
   - 功能：提供统一的卡片样式容器
   - 特点：支持多种卡片类型和主题
   - 接口：输入标题和内容，支持自定义样式
   - 样式：统一的圆角、阴影和间距
   - 交互：支持点击和长按事件

5. 任务项组件 (taskItem)
   - 功能：展示单个任务项
   - 特点：支持多种任务类型和状态
   - 接口：输入任务数据，输出点击、长按等事件
   - 样式：根据任务类型和状态显示不同样式
   - 交互：支持点击、长按、滑动等操作

6. 模板选择器组件 (template-selector)
   - 功能：用于快速选择任务模板
   - 特点：支持图标和文本双模式显示
   - 接口：输入模板列表，输出选择事件
   - 样式：支持多种布局和样式主题
   - 交互：点击选择，长按编辑，拖拽排序
   
7. 浮动菜单组件 (float-menu)
   - 功能：提供快速访问常用功能的浮动菜单
   - 特点：支持多级菜单，可自定义图标和位置
   - 接口：输入菜单配置，输出点击事件
   - 样式：圆形或方形，支持图标和文字
   - 交互：点击展开，动画过渡

8. 日期选择器组件 (date-picker)
   - 功能：提供日期选择界面
   - 特点：支持单日选择和范围选择
   - 接口：输入日期范围，输出选择结果
   - 样式：网格日历布局，支持多种主题
   - 交互：点击选择，滑动切换月份，动画效果
