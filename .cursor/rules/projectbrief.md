# 项目简介

## 项目目标
开发一个帮助小朋友养成良好学习习惯的微信小程序，通过任务管理、进度跟踪和奖励机制，培养小朋友的自律性和学习兴趣。

## 核心需求
1. 任务管理
   - 支持创建和编辑任务
   - 支持任务分类（习惯/学习）
   - 支持任务优先级设置
   - 支持重复任务设置

2. 进度跟踪
   - 实时显示任务完成进度
   - 支持多种进度展示方式
   - 提供历史数据查看

3. 奖励系统
   - 任务完成奖励
   - 连续打卡奖励
   - 多级奖励机制

4. 消息通知
   - 任务提醒
   - 奖励通知
   - 系统消息

## 技术栈
- 微信小程序原生开发
- ES6+ JavaScript
- 组件化开发
- 本地数据存储

## 项目范围
- 前端：微信小程序
- 后端：微信云开发
- 数据：本地存储 + 云数据库
