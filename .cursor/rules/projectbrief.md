# 学习任务微信小程序项目简介

## 项目概述
学习任务微信小程序是一个专为帮助小朋友养成良好学习习惯而设计的任务管理工具。通过简洁的界面和丰富的功能，帮助小朋友更好地规划和管理自己的学习任务。系统采用组件化设计，支持多种任务类型，提供丰富的进度跟踪和奖励机制。

## 项目目标
1. 帮助小朋友建立良好的学习习惯
2. 提供直观的任务进度跟踪
3. 通过奖励机制激励学习
4. 提供友好的用户体验
5. 支持多种设备适配
6. 提供丰富的统计分析

## 核心组件
1. 进度环组件 (progressRing)
   - 功能：圆环形进度显示
   - 特点：支持多种任务类型样式
   - 接口：输入进度百分比和类型，输出点击事件
   - 样式：支持default/habit/study/interest样式
   - 交互：点击事件，动画效果
   - 性能优化：渲染性能提升计划中

2. 任务热力图组件 (task-heatmap)
   - 功能：以热力图形式展示任务分布情况
   - 特点：支持月份导航、直观展示任务密度
   - 接口：输入任务数据，输出月份变更和日期选择事件
   - 样式：蓝色渐变热力展示，清晰的日历网格
   - 交互：点击日期查看当日任务，编辑任务信息
   - 编辑功能：支持修改任务积分和描述，支持循环任务编辑范围选择
   - 优化点：减少垂直空间占用，优化任务项UI，增强视觉效果

3. 进度条组件 (progressBar)
   - 功能：线性进度展示
   - 特点：支持多种样式和主题
   - 接口：输入进度百分比和类型，输出点击事件
   - 样式：支持default/habit/study/interest样式
   - 交互：点击事件，动画效果

4. 卡片容器组件 (card)
   - 功能：提供统一的卡片样式容器
   - 特点：支持多种卡片类型和主题
   - 接口：输入标题和内容，支持自定义样式
   - 样式：统一的圆角、阴影和间距
   - 交互：支持点击和长按事件

5. 任务项组件 (taskItem)
   - 功能：展示单个任务项
   - 特点：支持多种任务类型和状态
   - 接口：输入任务数据，输出点击、长按等事件
   - 样式：根据任务类型和状态显示不同样式
   - 交互：支持点击、长按、滑动等操作
