# 学习任务微信小程序项目简介

## 项目概述
学习任务微信小程序是一个专为帮助小朋友养成良好学习习惯而设计的任务管理工具。通过简洁的界面和丰富的功能，帮助小朋友更好地规划和管理自己的学习任务。系统采用组件化设计，支持多种任务类型，提供丰富的进度跟踪和奖励机制。

## 项目目标
1. 帮助小朋友建立良好的学习习惯
2. 提供直观的任务进度跟踪
3. 通过奖励机制激励学习
4. 提供友好的用户体验
5. 支持多种设备适配
6. 提供丰富的统计分析

## 项目范围
1. 任务管理功能
   - 创建和编辑任务
   - 设置任务类型（习惯/学习/兴趣）
   - 设置任务时间
   - 任务完成状态跟踪
   - 支持重复任务设置
   - 任务优先级管理
   - 任务分类管理
   - 任务提醒设置

2. 进度跟踪功能
   - 习惯养成进度

   - 兴趣培养进度
   - 可视化进度展示
   - 支持多种进度展示方式（圆环/进度条）
   - 实时进度更新
   - 历史数据查看
   - 进度统计分析

3. 统计分析功能
   - 任务完成率统计
   - 任务类型分布
   - 连续完成天数记录
   - 历史数据查看
   - 自定义统计周期
   - 数据可视化展示
   - 趋势分析
   - 对比分析

4. 奖励系统
   - 任务完成奖励
   - 连续打卡奖励
   - 奖励进度跟踪
   - 奖励解锁记录
   - 多级奖励机制
   - 奖励兑换系统
   - 奖励规则配置
   - 奖励历史记录

5. 消息通知
   - 任务提醒
   - 奖励通知
   - 系统消息
   - 消息中心管理
   - 消息分类展示
   - 消息状态管理
   - 消息推送设置
   - 消息历史记录

## 核心组件
1. 模板选择器组件 (template-selector)
   - 功能：展示和选择常用任务模板
   - 特点：支持多种任务类型样式
   - 全局注册：已在app.json中注册为全局组件
   - 接口：输入模板数据，输出选择事件
   - 样式：支持study/habit/interest三种主题样式
   - 交互：点击选择/自定义模板，触觉反馈

2. 进度环组件 (progressRing)
   - 功能：圆环形进度显示
   - 特点：支持多种任务类型样式
   - 接口：输入进度百分比和类型，输出点击事件
   - 样式：支持default/habit/study/interest样式
   - 交互：点击事件，动画效果
