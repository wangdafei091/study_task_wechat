# 产品上下文

## 问题陈述
用户需要一个简单易用的工具来管理日常任务和学习进度，特别是在移动端场景下。

## 解决方案
开发一个微信小程序，提供以下功能：
1. 任务创建和管理
2. 学习进度跟踪
3. 数据统计和分析
4. 提醒和通知

## 用户体验目标
1. 简单直观的界面
2. 快速响应的操作
3. 清晰的数据展示
4. 个性化的设置选项

## 目标用户
1. 学生
2. 职场人士
3. 需要管理任务和学习的个人

## 使用场景
1. 日常任务管理
2. 学习计划制定
3. 进度跟踪
4. 数据回顾和分析

## 竞争优势
1. 微信平台便捷性
2. 轻量级应用
3. 无需安装
4. 社交分享功能
