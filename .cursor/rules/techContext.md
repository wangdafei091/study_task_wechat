# 技术背景

## 开发环境
- 微信开发者工具
- Node.js >= 14.0.0
- npm >= 6.0.0
- 微信基础库 >= 2.19.0

## 项目结构
├── app.js # 应用入口
├── app.json # 应用配置
├── app.wxss # 全局样式
├── components/ # 自定义组件
├── pages/ # 页面文件
├── utils/ # 工具类
└── assets/ # 静态资源

## 核心工具类
1. dateUtils
   - 日期格式化
   - 日期计算
   - 日期比较

2. taskUtils
   - 任务统计
   - 任务过滤
   - 任务排序

3. messageManager
   - 消息创建
   - 消息发送
   - 状态管理

## 技术约束
1. 微信小程序限制
   - 包大小限制
   - API调用限制
   - 存储空间限制

2. 性能要求
   - 页面加载速度
   - 动画流畅度
   - 内存占用
